# JOORY.EXE Cyberpunk Portfolio

A responsive, game-menu-inspired portfolio for game development internship applications.

## Preview

Open `index.html` in your browser.

## Important edits

Open `index.html` and replace:

- `your-email@example.com`
- `yourusername` in GitHub and LinkedIn links
- Placeholder Unity and Game Jam project details
- `#` project links with your real GitHub, Itch.io, YouTube, or case-study links

Add your resume to the same folder and name it:

```text
resume.pdf
```

## Add images later

Create:

```text
images/
```

Then place your screenshots inside it. Example:

```text
images/unity-game.jpg
images/fareed.jpg
images/game-jam.jpg
images/smart-pill.jpg
images/profile.jpg
```

To replace a project background, update the matching class in `styles.css`.

Example:

```css
.visual-one {
  background:
    linear-gradient(to top, rgba(2,4,13,.9), transparent 70%),
    url("images/unity-game.jpg") center/cover;
}
```

## Publish using GitHub Pages

1. Create a public GitHub repository named `yourusername.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and `resume.pdf`.
3. Open repository **Settings**.
4. Open **Pages**.
5. Choose **Deploy from a branch**.
6. Choose `main` and `/root`.
7. Save.

Your link will be:

```text
https://yourusername.github.io
```
